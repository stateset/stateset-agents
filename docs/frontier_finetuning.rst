Frontier fine-tuning
===================

Pinned checkpoint identities, distributed text SFT, and explicit loader limits
for MiMo, GLM, Kimi, DeepSeek and Qwen are documented in the
`frontier fine-tuning guide <https://github.com/stateset/stateset-agents/blob/main/docs/FRONTIER_FINETUNING.md>`_.

Use ``stateset-agents frontier-models`` to inspect current readiness and
``stateset-agents frontier-sft --model glm5.3 --dry-run`` to preview a recipe.
Full-size GPU training is not yet certified for these new integrations.
