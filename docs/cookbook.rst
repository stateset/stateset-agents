Cookbook
========

Copy-paste recipes for the workflows that actually come up. Pairs with
:doc:`platform_tour` (the structured journey).

The canonical cookbook lives in ``COOKBOOK.md`` at the repo root, alongside
the platform tour. We keep it in Markdown so it renders well on GitHub and
pastes cleanly into PRs and Slack.

To read it:

* **On GitHub:** `docs/COOKBOOK.md <https://github.com/stateset/stateset-agents/blob/master/docs/COOKBOOK.md>`_
* **From a clone:** ``cat docs/COOKBOOK.md`` or open in any editor

Recipes covered
---------------

1. Your first fine-tune in 4 hours
2. Iterate from production conversation logs
3. Reproduce a whitepaper number
4. Build a tool-using agent
5. Run a batch evaluation against a trained checkpoint
6. Debug a stuck reward
7. Hand off to a colleague
8. Run the demos for a stakeholder
