# Modules allowed to import ``torch`` unguarded at module level.
#
# One ``path  # reason`` per line, relative to the repository root. These are
# modules that cannot do anything at all without torch — trainers, tensor
# backends and RL algorithm implementations — and that are only ever reached
# through a lazy import from a public package, so they never make an entry
# point pay for torch.
#
# The policy tests also reject STALE entries: a listed path must still exist
# and still contain an unguarded module-level torch import. The list can
# therefore only shrink deliberately. Do not add configuration modules, type
# modules, or anything under a torch-free entry point here — fix those instead.
