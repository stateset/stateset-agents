# Packaging A-Grade Fix Report

## Defects fixed

1. **Missing tag trigger** — added `push: tags: ['v*']` to `.github/workflows/publish.yml` alongside the existing `release: published` and `workflow_dispatch` triggers.
2. **Mangled version-check step** — the old step embedded a Python heredoc as a literal `\n`-escaped string inside a YAML `run: |` block, which is not valid bash (would hard-fail). Rewrote as a real multi-line `run:` block. It resolves the tag from `github.event.release.tag_name` (release event) or `${GITHUB_REF#refs/tags/}` (tag push), strips the leading `v`, and compares against `pyproject.toml`'s `project.version` via `python -c "import tomllib; ..."` (single-line, avoids YAML block-scalar indentation pitfalls with heredocs — confirmed this was the same root cause as defect 2, so also fixed the equivalent issue in the install-smoke step).
3. **No explicit build step** — added `rm -rf dist/`, `python -m build --sdist --wheel`, and `twine check dist/*` as explicit workflow steps (previously build only happened inside `make publish-readiness`, and stale `dist/` artifacts could leak into a release).
4. **Heavy readiness gate coupled to release** — `make publish-readiness` (bandit/safety/coverage) is no longer in the publish job's critical path. It now runs only when triggered via `workflow_dispatch` with `run_readiness_gate: true`, and with `continue-on-error: true` (non-blocking). The critical path is: verify version → build → twine check → install-smoke (fresh venv, install wheel, import `stateset_agents`, check `__version__`, load `stateset_agents.config.get_agent_preset('customer_service')`).
5. **OIDC trusted publishing** — switched both TestPyPI and PyPI publish steps to `pypa/gh-action-pypi-publish@release/v1`, added `permissions: id-token: write` (plus `contents: read`) at the job level, kept the `pypi` environment gating. `PYPI_API_TOKEN`/`TEST_PYPI_API_TOKEN` secrets are passed as the `password` input as a documented fallback if the OIDC trusted-publisher relationship isn't configured on PyPI yet; when unset, the action falls through to OIDC.
6. **Preset YAMLs missing from wheel** — `[tool.setuptools.package-data]` now includes `"config/presets/**/*.yaml"`. Added `MANIFEST.in` with prune rules for `htmlcov`, `outputs`, `checkpoints`, `benchmark_results`, `docs/_build`, `dist`, `build`, plus `global-exclude` for `*.log`, `coverage.xml`, `__pycache__`, `*.py[cod]`.
7. **Docs URL** — `[project.urls] Documentation` now points to `https://docs.stateset.ai` (matches the `docs-publish` job's actual gh-pages `cname`).
8. **CLI entry point** — verified `stateset_agents.cli:run` exists (`stateset_agents/cli.py:1270`, `def run() -> None`). No change needed.
9. **Makefile dead fallback** — removed `|| python setup.py sdist bdist_wheel` from the `build` target; no `setup.py` exists in this repo.
