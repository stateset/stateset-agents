Examples
========

Runnable examples live in the repo `examples/` directory.

Common starting points:

- `examples/quick_start.py`: lightweight demo (stub-friendly).
- `examples/finetune_kimi_k25_gspo.py`: Kimi-K2.5 fine-tuning with GSPO.
- :doc:`qwen3_5_starter`: built-docs quick start for post-training ``Qwen/Qwen3.5-0.8B``.
- :doc:`kimi_k2_6_starter`: built-docs quick start for post-training ``moonshotai/Kimi-K2.6``.
- :doc:`kimi_k3_starter`: built-docs quick start for post-training ``moonshotai/Kimi-K3`` (weights pending HF release).
- :doc:`muse_glimmer_starter`: built-docs quick start for post-training ``meta-models/Muse-Glimmer-30B``.
- :doc:`nemotron_3_5_starter`: built-docs quick start for post-training ``nvidia/NVIDIA-Nemotron-3.5-Lightning-30B-A3B-BF16``.
- :doc:`qwen3_8_starter`: built-docs quick start for post-training ``Qwen/Qwen3.8-27B``.
- :doc:`qwen3_coder_starter`: built-docs quick start for post-training ``Qwen/Qwen3-Coder-30B-A3B-Instruct``.
- :doc:`gpt_oss_starter`: built-docs quick start for post-training ``openai/gpt-oss-20b``.
- :doc:`deepseek_v4_starter`: built-docs quick start for post-training ``deepseek-ai/DeepSeek-V4-Flash``.
- ``docs/QWEN3_FINETUNING_GUIDE.md``: repository walkthrough for the same starter path.
