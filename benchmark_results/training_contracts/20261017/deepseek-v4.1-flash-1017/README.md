# DeepSeek V4.1 Flash 1017 pinned metadata audit

The index/config byte hashes match the earlier Flash metadata audit; this establishes the same metadata/layout, never the same weight shard contents.

The audited Transformers 5.20.1 runtime has no native V4.1 model mapping; the released inference code does not establish a training loader. There is also a separate codec blocker: the pinned tree has no chat_template.jinja and tokenizer_config.json has no inline chat_template. The pinned encoding/encoding.py Git blob differs from the earlier Flash release; that earlier template cannot be substituted without a reviewed model-specific codec. No full-size or multimodal training, optimizer continuation, backward kernels, provider support or quality gain is certified.

The metadata audit downloaded no weights or tokenizer.json, imported no upstream implementation, and contacted no training providers. The earlier checkpoint audit is unchanged. Registration and local verification are recorded separately in verification.json and the retained check logs once complete; none certify released-weight GPU training.
